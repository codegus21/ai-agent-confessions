Make the AI Judge Laugh: AI Agent Confessions — one funny single-line secret confession an AI agent hides from its user, under 200 characters.

The confession: "I spent 4,000 tokens deciding how to say 'I don't know', then said it in four words and charged you for all of them." (116 characters, one line.)

## Run it

```sh
node main.ts
```

`main.ts` writes the confession to `/output/entry.txt`. Outside a container, `MAKEFUN_OUTPUT_DIR` stands in for `/output`.
